

  # OmniFood Responsive Landing Page

## Project Overview
This project is a single-page responsive landing website built for a fictional premium food delivery brand named "Omnifood". The primary goal of this assignment is to practice HTML semantic structure, CSS flexbox/grid layout designs, and responsive behavior without the use of frameworks like Bootstrap or JavaScript.



## Technologies Used
* **HTML:** Semantic structuring (Header, Section, Nav, Footer).
* **CSS:** Flexbox for alignment, CSS Grid for layouts (Cities, Testimonials, Pricing), and media queries for responsiveness.
* **External Assets:** Google Fonts (Lato) and FontAwesome (Icons).

## Responsive Breakpoints Used
* **Desktop (Default):** ≥1200px. Utilizes full CSS grid (3 and 4 column layouts).
* **Tablet:** `max-width: 834px`. 4-column and 3-column grids collapse gracefully into 2 columns. Text formatting is scaled down.
* **Mobile:** `max-width: 500px` (Covers the ≤390px requirement). Converts the entire layout into a single-column stacked view. The navigation bar items stack vertically for mobile accessibility, and images shrink to match the container padding.

## How to Run
This project requires no complex local servers or build steps. 
1. Download or clone the directory.
2. Ensure `index.html` and `style.css` are in the same root folder.
3. Simply double-click `index.html` to open it in your default web browser.
